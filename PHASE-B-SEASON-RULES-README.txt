HOW TO TEST
1. Open admin.html and choose Prompt Studio.
2. Create a custom prompt.
3. Add a condition and choose Season played.
4. Test each operator.
5. Open Validation Lab and test wording such as:
   - Midfielder from the 2020/21 season
   - Midfielder before the 2020/21 season
   - Midfielder after the 2020/21 season
   - Midfielder between 2018/19 and 2022/23 seasons
6. In Season Health, run certification. It should now show 10/10 critical tests passed.
