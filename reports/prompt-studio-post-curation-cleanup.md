# Prompt Studio post-curation cleanup

Date: 8 September 2026

## Permanent boundary

Daily generation remains pinned to the frozen **4,897-prompt / 17-family** curated selector package. The promoted 134,765-prompt source snapshot remains separate provenance.

Prompt Studio is reduced to the maintained future-development path:

**Prompt Builder / Factory → Quality Analyser → Promotion + source archive → explicit versioned curated-authority update**

## Retired runtime / UI

The following completed Phase 1 paths are physically removed from the active repository runtime:

- 144-prompt curation review exporter;
- full-library evidence layer;
- survivor builder;
- pre-cutover curated package materialiser;
- standalone shadow-regression page/runtime;
- Refinement Incubator and survivor runtime;
- legacy four-star enforcement/finalizer runtime.

Their duplicate Phase 1 / Refinement workflows and implementation verifiers/scripts are also removed. Historical reports and the permanent curation policy remain as provenance/reference.

## Future families

`PROMPT_FAMILY_ONBOARDING.md` is the permanent contract. A future family can be built and promoted without affecting Daily. Entry into Daily requires a deliberate versioned selector/authority change plus the curated-authority and generation regression gates.

## Safety

This cleanup does not change the frozen selector IDs, the curated authority implementation, Daily generation rules, the 77-prompt weekly reservoir, publishing, Supabase or leaderboard behaviour.
